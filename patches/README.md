# Source patches

Keep project-specific source changes here only when they are small, reviewable patches against a documented upstream commit.

For every patch, record:
- Upstream repository and exact commit
- Why the patch is required for G9650 / Android 16
- Affected component and behavior
- Build validation
- Device test results

Prefer upstream changes or a maintained fork when practical. Do not put whole third-party source trees or proprietary vendor blobs into this directory.
